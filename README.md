# GoBarber Backend

Backend desenvolvido durante o Bootcamp GoStack da Rocketseat, com foco no aprendizado de desenvolvimento backend utilizando Node.js e TypeScript.

## Sobre o projeto

O GoBarber é uma aplicação voltada para agendamentos de serviços.

Neste backend, venho aplicando conceitos de desenvolvimento de APIs REST, organização de rotas, services, repositories, banco de dados e relacionamentos entre entidades.

## Tecnologias utilizadas

- Node.js
- TypeScript
- Express
- PostgreSQL
- TypeORM
- Docker
- Git e GitHub

## Conceitos praticados

Durante o desenvolvimento deste projeto, venho praticando:

- Criação de rotas HTTP
- Uso de `request` e `response`
- Services e regras de negócio
- Repositories
- Entities
- Migrations
- Relacionamentos entre tabelas
- Foreign Keys
- `ManyToOne` e `OneToMany`
- Operações assíncronas com `async` e `await`
- Integração com PostgreSQL através do TypeORM
- Uso do Docker para o ambiente do banco de dados

## Banco de dados

O projeto utiliza PostgreSQL em um container Docker.

A aplicação se conecta ao banco utilizando TypeORM e DataSource.
